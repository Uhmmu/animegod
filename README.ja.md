# AnimeGod

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語**

AnimeGod は、macOS 向けのネイティブでローカルファーストなアニメライブラリ兼
動画プレーヤーです——
**IINA × アニメライブラリ管理 × Bangumi/AniList × 自分だけの視聴日記** を、
ひとつの軽快な SwiftUI アプリにまとめました。

> ローカルのアニメコレクションに記憶・構造・背景・履歴を与えつつ、ネイティブ
> macOS アプリの速さと品質はそのままに。

**現在のバージョン：0.3.0。** AnimeGod は英語・簡体字中国語・日本語に対応し、
アプリ内で言語を切り替えられるようになりました。プレーヤーには新しいコントロールバー、
チャプター対応タイムライン、吹き出し型パネル、キーボードの早送り操作、分かりやすい
画面表示を追加。ライブラリはシステム設定に合わせるほか、ライトまたはダークに固定できます。

## 機能

### ライブラリ
- 複数のライブラリフォルダをセキュリティスコープ付きブックマークで管理。ボリューム
  名の変更や再マウント後もライブラリはそのまま使えます。
- 非破壊の再帰スキャン：ファイルの名前変更・移動・書き換えは一切しません。再スキャン
  しても視聴の進み具合は保たれます。
- アニメ向けのファイル名解析：`[Group] Title [01][1080p]`、`Title.S02E04`、
  小数話（`13.5`）、バージョン（`07v2`）、中国語表記（`第三季 第16集`、`第六章`）、
  NCOP/NCED/PV/Menu/MV/SP の分類。タイトルに付いた海賊版サイトの広告タグ
  （`【更多蓝光电影访问 www.…】`）や技術的な末尾（`2006 RERiP 1080p DTS-WiKi`）を
  取り除き、アダルト作品の品番（`SONE-615` など）は除外します。
- 1つのフォルダに2作品が入っている場合は別々の項目に分けます（前編/後編の総集編
  劇場版、まとめ劇場版など）。特典フォルダ（`SPs`、`特典`）は本編ではなく、その作品の
  特別編として扱います。
- 同じ劇場版の別エンコード（DoVi と SDR など）は1話にまとめ、プレーヤー内で
  バージョンを切り替えられます。既定は SDR です。
- **Blu-ray のディスクイメージ（`.iso`）も通常のエピソードと同じようにスキャン
  され**、マウントも展開もせずにそのまま再生できます。

### メタデータ
- **Bangumi**（v0 API：検索、ポスター、あらすじ、評価、スタジオ、作品のひとこと、
  コミュニティのトピック/レビュー）と **AniList**（GraphQL：検索、メタデータ、MAL の
  相互 ID、レビュー、主な制作スタジオ）にマッチします。
- **メタデータを検索** は未リンクの作品すべてに最も近い候補を割り当てます。怪しい
  候補は **マッチを確認** に回り、手早く確認できます。自動で推定したリンクには
  信頼度が表示され、**マッチを変更** で直せます。
- ソースごとのリンク・メタデータ・コミュニティの索引は SQLite にそれぞれ保存され、
  ソースが落ちていてもローカルライブラリは表示されます。コミュニティの項目は元の
  ページを開けます。
- ディスク上でフォルダ名を変えて再スキャンしても、リンクはファイルに付いていきます——
  メタデータ、個人の記録、視聴履歴は引き継がれます。

### リリース検索
- **リリース検索**（サイドバーの「見つける」、または各アニメページのツールバー）は
  10 のアニメ系トレントサイト——动漫花园、蜜柑计划、萌番组、Anime Garden、ACG.RIP、
  末日动漫、Nyaa（アニメカテゴリ）、AnimeTosho、SubsPlease、TokyoTosho——をまとめて
  検索し、サイトをまたいだ同じトレントを1件に統合します（16進/Base32 の info hash を
  正規化し、ソース・トラッカー・`.torrent` リンクをまとめます）。アニメのサイトのみを
  対象とし、アダルト・ゲーム・漫画の掲載は解析時に除外します。
- アニメページから開くと、その作品のすべての名前（Bangumi の中国語名と原題、AniList の
  ローマ字、フォルダ名）で一度に検索します。ライブラリに足りない話を含むリリースには
  **New** が付き、**Missing Episodes** でそれだけを表示できます。
- 各タイトルから字幕グループ、話数やまとめの範囲、解像度、コーデック、ソース、字幕の
  言語/形式（简/繁/日、内嵌/内封/外挂）を解析します。種類・解像度・字幕・グループで
  絞り込み、関連度・新しさ・シード数・サイズで並べ替えできます。関係の薄い掲載は
  既定で非表示です。
- 結果はサイトが応答するたびに順次表示されます。遅いサイトやブロックされたサイトが
  他を待たせることはありません。**Source Details** に各サイトの状態と所要時間が表示され、
  **Retry Failed** で失敗したものだけを再試行できます。
- 各リリースは、トレントアプリで開く、マグネットリンクをコピー（複数選択可）、
  `.torrent` を保存（info hash で検証）、掲載ページを開く、ができます。最近の検索を
  覚えています。

### ダウンロード
- **BitTorrent エンジン内蔵**（libtorrent を静的リンク）：別のクライアントなしで
  ダウンロードできます。終了しても進み具合は保存され、再起動後に再開します。一時停止、
  再開、削除（ファイルを消すかは選択）、ピアを増やすためのトラッカー再通知ができます。
- **ダウンロード**（サイドバーの「ソース」）に進捗、速度、シード/ピア数、残り時間、
  保存先を表示します。保存先は記憶され、ダウンロード開始時に使えない場合（ドライブが
  外れている、フォルダが削除された）は、使える直近のフォルダに切り替えて知らせます。
  どれも使えなければアプリ専用のフォルダに戻ります。
- **接続状況が見える**：BitTorrent の速度を左右するため、DHT ノード数と UPnP/NAT-PMP
  でポートを割り当てられたかを表示します。割り当てに失敗した場合は、手動で転送すると
  何が変わるかを説明します。
- **ダウンロードしながら再生**：順番どおりにダウンロードするタスクは、先頭の 32 MiB が
  ディスクに書かれると再生でき、AnimeGod のプレーヤーで開きます。残りはダウンロードを
  続け、そのファイルのピースを優先して再生位置より先に取得します。こうしたファイルは
  まだライブラリにないため、視聴の進み具合の記録・自動キャッシュ・弾幕のマッチは、
  ライブラリに入ってから行われます。
- **完了したらアーカイブを自動展開**：`.rar`、`.zip`、`.7z`（`part1`／`.001` の分割を
  含む）で配布されたリリースは、ダウンロードが終わるとその場で展開され、開けない
  ファイルではなくエピソードになります。元のアーカイブはそのまま残り、この動作は
  保存先メニューでオフにできます。
- **どのタスクにも専用のフォルダ**：単一ファイルの torrent も例外ではないので、
  保存先に `.mkv` が散らばりません。
- **完了したら自動でライブラリへ**：ライブラリフォルダ内に保存したタスクは完了時に
  再スキャンされ、通常のエピソードとして表示されます。別の場所に保存した場合は
  「ダウンロードフォルダをライブラリに追加」が表示されます。
- エンジンの設定は magnet-crawler の調整を引き継いでいます：複数の DHT ブートストラップ、
  ローカルピア検出、PEX、全トラッカーへの通知、暗号化は許可するが強制しない、IPv4 と
  IPv6 の両方で待ち受け、各タスクへの公開トラッカーの追加。

### 購読
- **放送中の作品を自動ダウンロード**：ルールは字幕グループ、解像度、字幕言語、含む/
  含まないキーワード、開始話数で構成します。「リリース検索」で絞り込んでからベルの
  ボタンを押すのが一番簡単です。
- **購読はこれから公開されるものだけを追います**：購読を作った後に公開されたリリース
  だけをダウンロードするので、シーズン途中で購読しても放送済みの全話を一度に
  取ってくることはありません。過去の話を補うには別のスイッチをオンにします。
- **1話につき1リリース**：ライブラリにあるものや以前ダウンロードしたものは取得しません。
  同じ話でシードのないリリースは、ピアのあるリリースに負けます。話数のないリリースは、
  ルールで字幕グループかキーワードを指定したときだけ自動でダウンロードし、シーズン
  まとめの誤ダウンロードを防ぎます。
- 合同リリースにも対応：ルールに `LoliHouse` と書けば `[喵萌奶茶屋&LoliHouse]` にも
  マッチします。字幕グループの実際の公開のしかたに合わせています。
- 有効なルールは 30 分ごとにチェックし、動作はすべて「Recent Activity」に記録します——
  自動ダウンロードは、見えて止められるときにだけ安心して使えるからです。

### Bangumi ランキング
- **Bangumi ランキング** では Bangumi が公開しているサイト全体のランキングを閲覧できます：
  5つのチャンネル（アニメ、書籍、音楽、ゲーム、実写）すべてと、サイトが提供する
  すべての絞り込み（カテゴリ/原作/ジャンル/地域/対象/プラットフォーム/レーティング…）を、
  チャンネルごとのメニューで選べます。
- 項目は読み取り専用の `next.bgm.tv/p1/subjects` JSON API（`sort=rank`）から取得します。
  絞り込みの分類は各チャンネルの閲覧ページから自動で見つけるので、新しい分類もアプリの
  更新なしに表示されます。bgm.tv の絞り込みサブパスは Cloudflare の検証で保護されて
  いるため、ランキング自体はそれらにアクセスしません。
- 各行にポスター、全体順位（金/銀/銅）、評価、評価数、あらすじを表示します。
  **さらに読み込む** で数千件までたどれます。ローカルライブラリでマッチ済みの作品には
  印が付き、詳細ページに直接移動できます。それ以外は bgm.tv のページを開きます。

### 翻訳
- 独立した翻訳サービス（`AnimeGodCore/Translation`）に **DeepL 互換 API** を内蔵：
  まとめてリクエスト、無料/Pro のエンドポイントを自動判別、API キーは AnimeGod の
  ローカル設定に保存、翻訳結果はローカルのデータベースにキャッシュします。
- 外国語のレビューは **原文と訳文を並べて表示** します——原文が置き換わることは
  ありません。

### 外観と言語
- 設定で システム / ライト / ダーク を選べます。プレーヤーのウインドウは常にダークです。
- 表示言語：English / 简体中文 / 日本語。設定の「言語」で切り替えます（再起動で反映）。

### プレーヤー
- libmpv（MPVKit）を内蔵した再生：H.264/HEVC/AV1、10-bit、VideoToolbox による
  ハードウェアデコード、複数の音声/字幕トラック、外部字幕の自動検出（`sub-auto=fuzzy` +
  `subs/字幕` フォルダ）、外部字幕の手動読み込み。
- **Blu-ray イメージ**：`.iso` を開くと本編がそのまま始まり、チャプターもシークも
  使えます。libbluray がイメージを直接読むのでマウントは不要で、サンドボックス内でも
  動き、余計なボリュームも残りません。DVD イメージは認識してその旨を伝えます。
- 常にダークな再生画面：上下のグラデーションの上にフラットなアイコンボタン。速度・音声・
  弾幕・字幕・バージョンは、ボタンから吹き出しのように上へ開くパネルで操作します。
- チャプターで区切られたタイムライン。ポインタを乗せると時間とチャプター名を吹き出しで
  表示し、ドラッグでなめらかにシークできます（時間をクリックすると残り時間表示に切り替え）。
- タイトルの横にエピソードの一覧パネル：本編 / SP / 音楽・OP/ED / 予告編 / 特典 に分けて
  格子状に表示します。チャプターメニュー、再生速度（0.5×–3×）、音量（クリックで消音、
  スクロールか `↑/↓` で調整）、字幕/音声の遅延。
- キーボード：`Space`、`F`、`N/P`、`D`、`M`、`↑/↓`、そして `←/→`：タップで 10 秒移動、
  長押しで 2 倍速、タップしてから長押しで 3 倍速（`←` は巻き戻し）。操作ごとに画面に
  表示が出ます。ダブルクリックでフルスクリーン。
- HDR：信号に基づく HDR10/HLG/Dolby Vision の判別、対応ディスプレイでの 16 ビット浮動小数点
  BT.2020 EDR 出力、自動の HDR→SDR トーンマッピング、診断パネル（**⌘⇧D**）。条件を満たす
  Dolby Vision Profile 8.4 の MP4/MOV は Apple ネイティブの再生経路を使い、MKV と
  Profile 7 は HDR10 ベースレイヤーを使います。

### エピソードキャッシュ
- **自動キャッシュ**：外付けドライブのエピソードを初めて再生すると、バックグラウンドで
  この Mac にコピーします（1つずつ、分割コピーで進捗をリアルタイム表示）。コピーが
  終わるまではドライブから再生を続けます。
- **見終わったら解放**：90% 以上まで再生して閉じると、そのエピソードの自動キャッシュを
  削除します——このコピーは初回再生から見終わるまでのバッファで、永久保存ではありません。
  手動キャッシュは自動では削除しません。
- **手動キャッシュ**：各エピソードにこの Mac へコピーするボタン（進捗表示とキャンセル付き）、
  アニメページには **すべてキャッシュ** があります。自動キャッシュ中のエピソードを手動で
  キャッシュすると、そのコピーをそのまま引き継ぎます。
- **オフライン再生**：外したドライブの項目も索引は残ります——キャッシュ済みのエピソードは
  普通に再生でき、それ以外はドライブの接続を求めます。再生時は完了したキャッシュを優先する
  ので、視聴中にドライブを外しても今見ている話は止まりません。
- **キャッシュマネージャ**（ソース → エピソードキャッシュ）：合計使用量、アニメごとの一覧と
  視聴済みの印、コピーの進捗、キャンセル、Finder で表示、1話ずつの削除、すべて消去、2つの
  自動ルールのスイッチ。コピーは `Application Support/AnimeGod/Episode Cache` に置かれ、
  起動時と再スキャンのたびにデータベースと照合します（孤立ファイルやクラッシュで残った
  途中のファイルを掃除します）。

### 弾幕
- 動画の上に重ねるネイティブのレンダラー（Core Animation のレイヤー + display link、文字の
  ビットマップをキャッシュ）。画面の上から並び、プレーヤー自身の時計に同期します。一時停止
  すると弾幕もすぐ止まり、シーク・速度変更・再開でも動画と同期を保ちます。レンダラーが
  HDR/EDR の映像経路に影響することはありません。
- 弾幕のソースは設定で選べます——**dandanplay**、**Bilibili**、または両方の統合：
  - 公式の **dandanplay Open Danmaku API**：ファイルのハッシュでエピソードを自動識別し、
    メタデータに基づく候補パネルも弾幕ボタンから開けます。候補はタイトル・話数・
    メディアの種類で並び、リリースのファイル名を検索欄にコピーする必要はありません。
    特殊なリリースはタイトルを手動で検索できます。
  - **Bilibili**：アカウント不要。Bilibili にはファイル識別の API がないため、タイトルと
    話数でエピソードをマッチし、公式の protobuf セグメント API から、その話自身の `cid` で
    弾幕を取得します——複数パートの投稿でも該当パートの弾幕を取得します。dandanplay で
    見つからない作品もここで見つかることがよくあります。任意の `SESSDATA` クッキー（設定で
    入力、ローカルに保存）は見られる範囲を広げるだけです。地域制限や会員限定の場合は
    そのように表示し、再生には影響しません。
  - **統合**：両方の弾幕を取得してまとめ、両方にあるコメントは1回だけ表示します。
- 取得した弾幕はソースとエピソードごとにローカルのデータベースへキャッシュし、オフラインでの
  再生や重複リクエストの回避に使います。最新の弾幕が欲しいときは **弾幕を更新** を使います。
- 再生バーの操作：オン/オフ（`D`）、不透明度、文字サイズ、行間、表示エリアと最大行数、
  流れる速さ、同時表示の上限、種類やカラーでの絞り込み、±10 秒のタイミング調整、更新と
  エピソードの再マッチ——すべて自動で保存されます。同じ行の弾幕は間隔を空け、入りきらない
  ものは重ねずに捨てます。[dev.dandanplay.com](https://dev.dandanplay.com) で無料の
  AppId/AppSecret を取得し、**設定** で入力してください。認証情報はローカルに保存されます。
- 弾幕の多い作品向けの絞り込み：10 秒以内の重複コメントは ×N 付きで1つにまとめ、密度の
  スライダーで残りを均等に間引けます（何度も繰り返されたコメントは常に残ります）。長すぎる
  コメントを隠せ、ブロックするキーワードは普通の文字列か `/正規表現/` で指定できます。
- **弾幕マネージャ**（`M` キー、または弾幕のパネルから）：動画の横に開くパネルで、直近 30 秒の
  コメントを一覧表示するか、その話の全コメントを検索できます。コメントをクリックするとその
  時間へ移動し、右クリックでその文字列や投稿者をブロックできます。非表示になったコメントには
  どのルールで隠れたかが表示され、ブロックしたキーワードとユーザーはパネルか弾幕の設定で
  管理できます。

### オンライン字幕
- 動画に優先言語（既定は簡体字/繁体字の中国語）の字幕がないとき、AnimeGod は作品・
  シーズン・話数・リリース（字幕グループ/エンコードグループ、BD/WEB のソース、解像度）を
  識別し、設定済みの字幕サイトを並行して検索します。十分に確かなときだけ最良の結果を
  自動で読み込み、そうでなければ小さな表示で候補を選んでもらいます。
- 字幕のソース（それぞれのキーは設定で入力し、キーチェーンではなく AnimeGod のローカル設定に
  保存）：**射手网(伪) assrt.net**（中国語字幕グループのアーカイブ、ASS）、**SubDL**（TMDB ID +
  シーズン/話数で検索）、**OpenSubtitles**（ファイルハッシュで完全一致、SRT のみ）、
  **Jimaku**（日本語字幕、日本語を優先するときのみ使用）。どれか1つが失敗しても他には
  影響しません。
- マッチはまず同じ話か、リリースに合うかを見ます——BD の字幕が WEB の動画に自動で読み込まれる
  ことはなく、その逆もありません——その次に言語と形式の順位（ASS/SSA を SRT より優先）を
  見ます。シーズンパックや ZIP からは該当する話を取り出し、GBK/Big5 は UTF-8 に変換します。
- 字幕のパネルは **埋め込み**、**外部ファイル**、**オンライン** の3つに分かれています。
  **オンライン字幕** には自動マッチ、**字幕を検索…**（言語、形式、ソース、字幕グループ、
  一致度、バージョン、ファイル名）、ダウンロード済みの字幕があります。ダウンロードした字幕は
  話ごとにキャッシュされ、見直すときに再検索は不要です。ASS は libass で描画し、字幕パックに
  含まれるフォントを使います。
- ファイル名から中国語字幕が焼き込まれているとわかるリリース（`[CHT]`、`[简日内嵌]` など）は
  既定で検索しません。設定で変更できます。

### 個人の記録
- 視聴記録は実際の再生セッションから作られます（15 秒未満の再生は無視）。90% まで再生すると
  その話を視聴済みにし、視聴状況も自動で更新します。
- 作品ごとに状態、評価、メモ、レビュー、タグ、お気に入り、再視聴回数を設定できます——
  **順位と評価は完全に別** で、**マイランキング** で並び替えられます。
- **視聴日記** は視聴履歴から自動で作られます。
- **統計** は1年をレポートにします：合計視聴時間、セッション数、見終わった話数、月/曜日/
  時間帯別の視聴傾向、よく見たアニメとスタジオ、高く評価した作品——すべてローカルで
  計算します。

## 開発

必要環境：macOS 14+、Xcode 26+、XcodeGen。

```sh
swift test
xcodegen generate
xcodebuild -project AnimeGod.xcodeproj -scheme AnimeGod -configuration Release build
```

- `AnimeGodCore`（SPM パッケージ）にはモデル、GRDB のデータベース、スキャナ/パーサ、
  メタデータのソース、翻訳、統計が入っており、単体でテストできます。
- アプリのターゲットは SwiftUI + AppKit で、再生には LGPL 版の MPVKit を使います。
  バイナリを配布する前に `THIRD_PARTY_NOTICES.md` をお読みください。
- 表示文字列は String Catalog（`App/Localizable.xcstrings`、
  `Sources/AnimeGodCore/Resources/Localizable.xcstrings`）にあります。コマンドラインで
  ビルドした後は `scripts/sync-localizations.sh DerivedData/<task>` で取り込み、
  `scripts/check-localizations.py` で未翻訳を確認します。
- オンラインのソースを使うテスト（任意）：`ANIMEGOD_LIVE_TESTS=1 swift test --filter
  'Bangumi.*ProviderTests'`。
- UI なしのプレーヤーのスモークテスト：ビルドしたバイナリを `-smokePlayerTest` 付きで実行
  （第1話を自動再生し、フルスクリーンを切り替え、レイアウトの寸法を出力）。
  `-AppleLanguages "(ja)"` を付けると日本語の UI で実行できます。

## データとプライバシー

ライブラリ、メタデータのキャッシュ、視聴履歴、個人の記録、統計、翻訳、弾幕のマッチ、
弾幕のキャッシュ、エピソードキャッシュの索引——すべてのデータはローカルの SQLite
データベース（`~/Library/Containers/com.uhmmu.AnimeGod/Data/…`）に保存され、キャッシュした
エピソードのファイルは同じコンテナの Application Support フォルダにあります。何かを
アップロードすることはありません。ネットワークを使うのは、メタデータのソースを使うとき、
Bangumi ランキングを見るとき、設定した翻訳サービスを使うとき、弾幕をオンにして選んだ
ソース（dandanplay と/または Bilibili）にアクセスするとき、設定した字幕サイトにアクセスする
とき（作品名、ID、話数、ファイル名を送信し、OpenSubtitles にはファイルの 128 KiB から計算した
ハッシュも送ります）、リリースのサイトを検索するとき、そしてダウンロード時に BitTorrent
ネットワークにつながるときだけです。BitTorrent は P2P のプロトコルなので、他のトレント
クライアントと同じく、データをやり取りする相手からは IP アドレスが見えます。
