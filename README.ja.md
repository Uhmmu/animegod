# AnimeGod

**macOS 向けのネイティブでローカルファーストなアニメライブラリ兼プレーヤー。**

すでに持っているフォルダを AnimeGod に指定するだけです。字幕組の命名規則どおりに
ファイル名を読み、Bangumi と AniList で作品を見つけ、libmpv で再生し、弾幕を重ね、
観たものを憶えておく——すべてあなたの Mac の中で完結します。アップロードもリネームも
移動も、一切しません。

## はじめかた

1. **[最新の DMG をダウンロード](https://github.com/Uhmmu/animegod/releases/latest)** して、AnimeGod を「アプリケーション」へドラッグします。
2. 起動して **ライブラリフォルダを追加** から、アニメの置き場所を選びます。外付けドライブでも構いません。
3. スキャンが終わったら **メタデータを検索** を押して、あとは観るだけです。

> アドホック署名のみで、公証（notarization）は受けていません。初回起動時は
> 右クリックして **開く** を選ぶ必要がある場合があります。

**現在のバージョン：0.3.2** —— セットでダウンロードした 1 シーズンが、ようやく
「ひとつの作品」として振る舞うようになりました。フォルダはひとつ、ホーム画面の
カードもひとつ（実物のカバー付き）、しかも 1 話目が終わる前にはもう作品と
紐づいています。ダウンロードし終えたものはキューに引き戻されることなくシードを
続け、Finder でファイルを動かしたタスクは、もう一度ダウンロードし直すのではなく
一時停止するようになりました。

## ライブラリ

ファイルはそのままです。AnimeGod は読むだけです。

- **リネーム・移動・書き換えは一切しません** —— 再スキャンしても同じです。
- **字幕組のファイル名を理解します**：`[Group] Title [01][1080p]`、
  `Title.S02E04`、`第三季 第16集`、小数話（`13.5`）、バージョン（`07v2`）。
- **複数のライブラリフォルダ**。外付けドライブも、名前変更や再マウントを越えて使えます。
- **Blu-ray の `.iso` イメージも通常のエピソードと同じようにスキャンします。**

<details>
<summary>もう少し詳しく</summary>

- セキュリティスコープ付きブックマークにより、ボリューム名を変えても再マウントしても
  外付けドライブはそのまま使えます。
- NCOP/NCED/PV/Menu/MV/SP は本編一覧に混ぜず分類します。海賊版サイトの広告タグ
  （`【更多蓝光电影访问 www.…】`）や技術的な末尾（`2006 RERiP 1080p DTS-WiKi`）は
  タイトルから取り除きます。
- アダルト作品の品番（`SONE-615` 形式）はライブラリから除外します。
- ひとつのフォルダに 2 作品が入っている場合は別々の項目に分けます（前編/後編の
  総集編劇場版、まとめ劇場版など）。特典フォルダ（`SPs`、`特典`）は、その作品の
  特別編として作品に残します。
- 同じ劇場版の別エンコード（DoVi と SDR など）は 1 話にまとめ、プレーヤー内で
  バージョンを切り替えられます。既定は SDR です。
- ディスク上でフォルダ名を変えて再スキャンしても、同一性の引き継ぎによりメタデータ・
  個人の記録・視聴履歴はファイルについて回ります。

</details>

## メタデータ

- **Bangumi**（ポスター、あらすじ、評価、スタジオ、吐槽箱、トピック、ブログ）と
  **AniList**（メタデータ、MAL の相互 ID、レビュー、スタジオ）。
- **メタデータを検索** が未リンクの作品を最有力候補に結び付け、怪しいものだけを
  **候補を確認** に回して人の判断に委ねます。
- **提供元が落ちてもライブラリは隠れません** —— 紐付けと取得内容は SQLite に
  それぞれ独立して保存されます。

<details>
<summary>もう少し詳しく</summary>

- 自動で推測したリンクは確信度を表示し、**リンクを変更** で直せます。
- コミュニティ項目（吐槽箱、トピック、ブログ、レビュー）は元のページを開きます。
- Bangumi は v0 API、AniList は GraphQL を使用します。

</details>

## プレーヤー

libmpv（MPVKit）をネイティブウインドウに埋め込み、映像の上では常に暗いままの
コントロールを重ねています。

- **HDR をきちんと**：信号に基づく HDR10/HLG/Dolby Vision 判定、対応ディスプレイでの
  BT.2020 EDR 出力、自動トーンマッピング、診断パネル（**⌘⇧D**）。
- **Blu-ray イメージ**は本編へ直行。マウントなしでチャプターもシークも使えます。
- **チャプター目盛り付きタイムライン**。ホバーで時刻とチャプターを表示し、
  ドラッグでなめらかにスクラブできます。
- **話数ピッカー**をタイトルの横に。本編 / SP / 音楽・OPED / PV / 特典に分類されます。

<details>
<summary>対応形式・操作・キーボード</summary>

- H.264/HEVC/AV1、10bit、VideoToolbox によるハードウェアデコード、複数音声・字幕トラック、
  外部字幕の自動検出（`sub-auto=fuzzy` と `subs`/`字幕` フォルダ）、手動での外部字幕読み込み。
- 上下のスクリム上にフラットなアイコンコントロール。速度・音声・弾幕・字幕・バージョンは
  ボタンから膨らむバブルパネルとして開きます。
- チャプターメニュー、再生速度 0.5×〜3×、音量（クリックでミュート、スクロールまたは `↑/↓`）、
  字幕と音声のディレイ。
- キーボード：`Space`、`F`、`N`/`P`、`D`、`M`、`↑/↓`、`←/→`（タップで 10 秒シーク、
  長押しで 2 倍速、タップしてから長押しで 3 倍速）。すべて画面上にフィードバックが出ます。
  ダブルクリックで全画面。
- 条件を満たす Dolby Vision Profile 8.4 の MP4/MOV は Apple ネイティブの再生経路を使います。
  MKV と Profile 7 は HDR10 のベースレイヤーを使用します。DVD イメージは認識して
  その旨を伝えるだけで、再生はしません。

</details>

## 弾幕 (Danmaku)

Core Animation が映像の上にネイティブで描画し、プレーヤー自身の時計に同期します——
一時停止すれば即座に止まり、シークや速度変更でも映像とずれません。HDR パイプラインには
一切触れません。

- **2 つのソースを統合**：dandanplay、Bilibili、またはその両方（重複は 1 件に）。
- **dandanplay** はファイルハッシュで話数を特定するため、リリース名を検索欄に
  貼り付ける必要がありません。
- **Bilibili はアカウント不要**。任意の `SESSDATA` クッキーは、自分のアカウントで
  見える範囲を広げるだけのものです。
- **弾幕マネージャー**（`M`）：直近 30 秒、またはエピソード全体を検索。コメントを
  クリックするとその位置へ、右クリックで本文や投稿者をブロックできます。

<details>
<summary>フィルタ・操作・キャッシュ</summary>

- コメントが多い作品向け：10 秒以内の重複は ×N 表示にまとめ、密度スライダーで均等に間引き、
  長いコメントを隠せます。NG ワードはプレーンテキストでも `/正規表現/` でも指定できます。
- プレーヤーバーの設定はすべて記憶されます：オン/オフ（`D`）、不透明度、文字サイズ、行間、
  表示領域と最大行数、流れる速さ、同時表示数、モード別・色付きコメントのフィルタ、
  ±10 秒のオフセット、再取得とエピソードの再マッチ。
- 同じレーンのコメントは間隔を保ち、入りきらないものは重ねずに捨てます。
- コメントは提供元・エピソードごとにキャッシュされ、オフラインでも再生できます。
  再取得するのは **弾幕を再取得** だけです。
- dandanplay には [dev.dandanplay.com](https://dev.dandanplay.com) の無料な
  AppId/AppSecret が必要です（**設定** で入力）。
- Bilibili にはファイル同一性の API がないため、タイトルと話数から該当話の `cid` を割り出し、
  公式の protobuf エンドポイントから読み込みます（複数パート投稿では正しいパートを選びます）。
  地域制限のある作品はその旨を表示し、再生には影響しません。

</details>

## オンライン字幕

希望する言語（既定では簡体字・繁体字中国語）の字幕が動画にない場合、AnimeGod は作品・
シーズン・話数・リリースを割り出し、4 つのサイトを並行して検索して、最良の候補を自分で
読み込みます——ただし確信があるときだけです。そうでなければ小さなバッジが候補を提示します。

- **射手網(偽) assrt.net**、**SubDL**、**OpenSubtitles**、**Jimaku**（日本語のみ）。
  それぞれ設定に個別のキーがあり、ひとつ失敗しても他には影響しません。
- **BD 用字幕が WEB 版の動画に自動で当てられることはありません**（逆も同様）。
- シーズンパックや ZIP は該当話へ展開し、GBK/Big5 は UTF-8 に変換、ASS は字幕パック同梱の
  フォントを使って libass で描画します。

<details>
<summary>もう少し詳しく</summary>

- 字幕メニューは **内蔵**・**外部ファイル**・**オンライン** に分かれます。
  **字幕を検索…** では言語・形式・提供元・グループ・一致度・バージョン・ファイルを選べます。
- ダウンロードした字幕はエピソードごとにキャッシュされ、次回は検索せずに読み込まれます。
- マッチングは、同じ話数と互換性のあるリリースを最優先し、次に言語と形式の優先順
  （SRT より ASS/SSA）を見ます。
- 中国語字幕が焼き込まれていることが名前から分かるリリース（`[CHT]`、`[简日内嵌]`）は
  既定でスキップします（設定で変更可）。
- キーはキーチェーンではなく、AnimeGod のローカル設定ファイルに保存されます。

</details>

## リリース検索

10 のアニメ索引を同時に検索します——动漫花园、蜜柑计划、萌番组、Anime Garden、ACG.RIP、
末日动漫、Nyaa、AnimeTosho、SubsPlease、TokyoTosho。同じトレントの掲載はサイトを
またいで 1 件にまとめます。対象はアニメ索引のみで、アダルト・ゲーム・漫画の掲載は
解析の段階で落とします。

- **作品から検索**すると、知っている名前がすべて同時に飛びます（Bangumi の中国語名と
  原題、AniList の romaji、フォルダ名）。手元にない話数を含むリリースには **New** が付きます。
- **「エピソードセット」は、40 GB のバッチを落としたくない人への答えです。** 同じ検索結果を
  字幕組のシーズン単位に組み直したもので、話数以外のすべて——字幕組、シーズン、解像度、
  コーデック、ソース、字幕言語——が一致したものだけをまとめます。1080p 簡日が 720p 繁日と
  同じ山に入ることはありません。クリックひとつで全話が始まります。
- **欠けた話は隣の字幕組から補います**：その組が出していない話は最も近い別のラインから
  取り、「借りてきた」と明示します。字幕付きシーズンに生ファイルを混ぜることはありません。
  1 組だけで 1 シーズンを賄えないときは、複数の字幕組をまたいで組み立てた行がもう 1 つ増えます。
- **結果は届いた順に流れてきます**。遅いサイトやブロックされたサイトが他を待たせません。

<details>
<summary>フィルタ・診断・細かい話</summary>

- すべてのタイトルから字幕組、話数またはバッチ範囲、解像度、コーデック、ソース、字幕の
  言語と形式（簡/繁/日、内嵌/内封/外挂）を解析します。種類・解像度・字幕・グループで絞り込み、
  一致度・新着・シード数・サイズで並べ替えられます。無関係な掲載は既定で隠れます。
- 各セットには、そのシーズンをどれだけ覆っているか、合計サイズ、そして最も弱いスウォームが
  表示されます——1 話が枯れているだけでシーズン全体が止まるからです。すでにライブラリに
  ある話はスキップし、誰も出していない話は名前を挙げ、ほとんど他組のファイルになるような
  「シーズン」はシーズンとして提示しません。
- 続編は別勘定です。S2 と付いて 1〜10 と振られたシーズンは、同じ検索の中で 29〜38 と
  数え続けている組とではなく、自分の番号付けで測ります。
- **ソースの詳細** で各ソースの状態と所要時間を確認でき、**失敗したものを再試行** は
  失敗したものだけを再実行します。
- リリース単位で、他の Torrent アプリで開く、マグネットをコピー、`.torrent` を保存
  （info hash で検証）、掲載ページを開く、ができます。最近の検索語は記憶されます。

</details>

## ダウンロード

**BitTorrent エンジンを内蔵**（libtorrent を静的リンク）しているので、リリースを
落とすのに他のアプリは要りません。

- **ライブラリフォルダへ直接**。完了したものは何も動かさずに通常のエピソードとして
  スキャンされます。
- **1 シーズンはひとつのフォルダに**収まります。12 個のフォルダが並ぶのではなく、
  作品名のフォルダひとつです。
- **1 シーズンはライブラリのカード 1 枚**。実物のカバーと進捗リングひとつで表示され、
  エピソードが届いている最中でもカードから作品ページを開けます。
- **終わる前にマッチします**：ライブラリが知らない作品のダウンロードを始めると、
  どの作品かを一度だけ（シーズン全体につき 1 回）尋ねます。あとから手作業で
  紐づける必要はありません。
- **1 シーズンは殺到ではなく順番待ち**：同時に 4 件（フォルダメニューで 1〜8）、
  残りは話数順に待ちます。
- **ダウンロードしながら再生**：先頭 32 MiB がディスクに載った時点で、再生ボタンが
  AnimeGod 自身のプレーヤーで開きます。残りはその間も届き続けます。
- **完了したアーカイブは自動展開**。`.rar`/`.zip`/`.7z` のリリースが、開けないファイルの
  ままではなくエピソードになります。

<details>
<summary>もう少し詳しく</summary>

- 終了してもタスクは再開し、位置を保ちます。一時停止・再開・削除（ファイルを残すかは選択）・
  トラッカーへの再通知ができます。
- どのタスクにも専用フォルダが与えられます（単一ファイルのトレントも含む）ので、
  ダウンロード先が裸の `.mkv` で埋まることはありません。1 話ずつ落としたものは、
  あとからダウンロード一覧でひとつのフォルダにまとめられます——ファイルはエンジンが
  動かすのでシードは途切れず、空になったフォルダは自動で片付きます。
- **完了したリリースはシードを続けます。** シード枠はダウンロード数とは連動しません。
  上りしか使わず、ダウンロードには常に先に枠が回るからです。
- **ファイルを動かしたタスクは一時停止し、再ダウンロードはしません。** 観終わった話を
  Finder で移動するのは普通の操作であり、その答えが 600 MB の再取得であってはなりません。
- フォルダメニューにはライブラリフォルダと最近使ったフォルダが並び、開始後でも中断せずに
  移動できます。開始時にフォルダが使えない場合（ドライブ未接続、フォルダ削除）は、
  次に使えるフォルダを使ってその旨を伝えます。
- **接続状況が見えます**。BitTorrent の速度を決めるのはそこだからです：DHT のノード数、
  UPnP/NAT-PMP がポートを開けたかどうか、開かなかった場合に手動転送で何が得られるかの説明。
- ライブラリ外に保存したタスクには **ダウンロードフォルダをライブラリに追加** が出ます。
- ライブラリに入る前に再生したファイルは、視聴進捗・自動キャッシュ・弾幕マッチを
  記録しません。スキャンされてからになります。
- エンジンの調整：複数の DHT ブートストラップノード、ローカルピア探索、PEX、
  全トラッカーへの通知、暗号化は許可するが強制しない、IPv4 と IPv6 の両対応、
  そして全タスクへのコミュニティトラッカー追加。

</details>

## 購読

作品をフォローすれば、新しい話数が自分で降りてきます。ルールを作る一番早い方法は、
リリース検索でフィルタが望みどおりになった状態でベルのボタンを押すことです。

- **フォローは「これから」です** —— シーズン途中で購読しても、すでに出ている分を
  一気に引っ張ってきたりはしません。遡っての取得は明示的なスイッチです。
- **1 話につき 1 リリース**。すでにライブラリにあるもの、以前落としたものは選ばれず、
  誰もシードしていないリリースはピアのいるものに負けます。
- **すべての動作が一覧に残ります**（最近の動作）。自動ダウンロードは、見えていて、
  すぐ止められるときだけ安心して使えるものです。

<details>
<summary>もう少し詳しく</summary>

- ルールは、字幕組・解像度・字幕言語・必須/除外キーワード・話数の下限で構成されます。
- 話数のないリリースは、ルールが字幕組かキーワードを指定しているときだけ取ります。
  シーズンパックを誤ってつかむことはありません。
- 共同制作も数に入ります。`LoliHouse` を指定したルールは `[喵萌奶茶屋&LoliHouse]` にも
  一致します——実際の字幕組のリリースはそうなっているからです。
- 有効なルールは 30 分ごとに確認されます。

</details>

## エピソードキャッシュ

外付けドライブに置いてあるアニメのための機能です。

- **自動キャッシュ**：最初に再生したとき、バックグラウンドでこの Mac にコピーします。
  再生自体はドライブから読み続けます。
- **観たら解放**：90 % 以上でエピソードを閉じると、その自動キャッシュは削除されます。
  このコピーは初回再生から観終わるまでの緩衝材であって、複製ではありません。
- **オフライン再生**：ドライブを抜いても索引は残ります。キャッシュ済みの話は普通に再生でき、
  それ以外は「请插入硬盘」と表示されます。

<details>
<summary>もう少し詳しく</summary>

- 各話の行から手動でキャッシュ（進捗表示・中止あり）、または作品ページの **すべてキャッシュ**。
  手動のコピーが自動削除されることはありません。すでに自動キャッシュ中の話を要求した場合は、
  そのコピーを引き継ぎます。
- 再生は完成したキャッシュをドライブより優先するので、シリーズの途中でディスクを抜いても
  再生中の話は止まりません。
- **キャッシュマネージャー**（ソース → エピソードキャッシュ）：合計サイズ、作品ごとの
  グループ表示と視聴済みバッジ、進捗、中止、Finder で表示、話ごとの削除、全消去、
  2 つの自動ルールの切り替え。
- コピーは `Application Support/AnimeGod/Episode Cache` に置かれ、起動時と再スキャンのたびに
  データベースと突き合わせます。孤立したファイルやクラッシュで残った断片は片付けられます。

</details>

## Bangumi ランキング

Bangumi が公開しているサイト全体のランキングをすべて：5 つのチャンネル（アニメ、書籍、音楽、
ゲーム、実写）と、サイトが提供するすべてのフィルタ（分类/来源/题材/地区/受众/平台/分级…）を、
チャンネルごとにひとつのメニューへまとめています。

<details>
<summary>もう少し詳しく</summary>

- ランキング行はカバー、サイト順位（金銀銅の表彰台）、スコア、評価数、情報行を表示します。
  **もっと読み込む** で数千件までページングできます。
- すでにライブラリにある作品にはバッジが付き、詳細ページへリンクします。それ以外は
  bgm.tv のページを開きます。
- 項目は読み取り専用の `next.bgm.tv/p1/subjects`（`sort=rank`）から取得し、フィルタの分類は
  各チャンネルのページから発見するため、アプリを更新しなくても新しいカテゴリが出てきます。

</details>

## 視聴記録

- **視聴イベントは実際の再生から**生まれます（15 秒未満の接触は無視）。90 % で視聴済みとなり、
  追跡ステータスが更新されます。
- 作品ごとに **ステータス・スコア・メモ・レビュー・タグ・お気に入り・再視聴回数**。
  **ランキングはスコアとは厳密に別**に保たれ、「マイランキング」で並べ替えられます。
- **アニメ日記** は視聴履歴から生成されます。
- **統計** は 1 年をレポートにします：視聴時間、セッション数、完走した話数、月別・曜日別・
  時間帯別の傾向、最も観た作品とスタジオ、自分の高評価作品——すべてローカルで計算します。

## 翻訳

DeepL 互換の翻訳プロバイダ（リクエストをまとめる、free/pro エンドポイントの自動判別、
結果はローカルにキャッシュ）を、外国語のレビューに使います。レビューは
**原文と訳文を並べて**表示し、原文が置き換わることはありません。

## 外観と言語

システム / ライト / ダーク。プレーヤーウインドウは常に暗いままです。インターフェースは
**English、简体中文、日本語** に対応しています（設定 → 言語、再起動後に反映）。

## 開発

必要なもの：macOS 14 以降、Xcode 26 以降、XcodeGen。

```sh
swift test
xcodegen generate
xcodebuild -project AnimeGod.xcodeproj -scheme AnimeGod -configuration Release build
```

- **`AnimeGodCore`**（SPM パッケージ）にモデル、GRDB データベース、スキャナ／パーサ、
  メタデータプロバイダ、翻訳、統計が入っています。単体でテストできます。
- **アプリターゲット**は SwiftUI + AppKit と、LGPL ビルドの MPVKit を使います。
  バイナリを配布する前に `THIRD_PARTY_NOTICES.md` を確認してください。
- 画面の文字列は String Catalog にあります。コマンドラインでビルドしたあと、
  `scripts/sync-localizations.sh DerivedData/<task>` で新しい文字列を取り込み、
  `scripts/check-localizations.py` が未翻訳を一覧します。
- 任意のライブプロバイダテスト：
  `ANIMEGOD_LIVE_TESTS=1 swift test --filter 'Bangumi.*ProviderTests'`。
- ビルド済みバイナリに対するヘッドレスのスモークテスト：`-smokePlayerTest`
  （最初の話を再生し、全画面を切り替え、レイアウトのサイズを出力）、
  `-smokeEpisodeSets "<title>"`（実際の索引からシーズンを組み立てる）、
  `-smokeAppearanceSnapshots`。`-AppleLanguages "(ja)"` を付ければ別の言語で動かせます。

## データとプライバシー

すべてあなたの Mac の中にあります——ライブラリ、メタデータのキャッシュ、視聴履歴、
個人の記録、統計、翻訳、弾幕のマッチ、コメントのキャッシュ、エピソードキャッシュの索引は
すべてローカルの SQLite データベース（`~/Library/Containers/com.uhmmu.AnimeGod/Data/…`）に
あり、キャッシュした動画も同じコンテナに置かれます。**何もアップロードしません。**

ネットワークを使うのは、あなたが求めたことだけです：あなたが呼び出したメタデータ
プロバイダ、Bangumi ランキング、設定した翻訳プロバイダ、有効にした弾幕ソース、設定した
字幕サイト（タイトル・ID・話数・ファイル名、OpenSubtitles には 128 KiB から算出した
ハッシュも送ります）、検索したリリース索引、そして開始したダウンロードのスウォーム。
BitTorrent はピアツーピアなので、データをやり取りするピアにはあなたの IP アドレスが
見えます——これはどの Torrent クライアントでも同じです。
