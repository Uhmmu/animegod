# AnimeGod

[English](README.md) | **简体中文**

AnimeGod 是一款原生、本地优先的 macOS 动画库与视频播放器——
**IINA × 动画库管理器 × Bangumi/AniList × 个人追番日记**，
集成在一个快速的 SwiftUI 应用中。

> 让本地动画收藏拥有记忆、结构、背景与历史，同时保留原生 macOS
> 应用的速度与品质。

**当前版本：0.2.0。** 现在可以同时搜索十个动漫种子站，用内置 BitTorrent
引擎下载、边下边播，并订阅之后更新的剧集。弹幕也新增 Bilibili 数据源，可与
弹弹play 单独使用或合并显示。

## 功能

### 动画库
- 支持多个媒体库根目录，使用安全作用域书签；卷宗改名或重新挂载后媒体库
  依然有效。
- 非破坏性递归扫描：从不重命名、移动或修改文件；重新扫描时保留观看进度。
- 面向动画的文件名解析：`[Group] Title [01][1080p]`、`Title.S02E04`、
  小数集（`13.5`）、版本号（`07v2`）、中文格式（`第三季 第16集`、`第六章`），
  NCOP/NCED/PV/Menu/MV/SP 分类；自动去除标题中的盗版站广告标签
  （`【更多蓝光电影访问 www.…】`）和技术尾缀（`2006 RERiP 1080p DTS-WiKi`），
  并排除成人影片编号（`SONE-615` 这类）。
- 一个文件夹里包含两部作品时会拆分成独立条目（前篇/後篇总集篇电影、合集
  电影）；特典文件夹（`SPs`、`特典`）作为特别篇归属于对应作品，而非正片。
- 同一部电影的不同编码版本（例如 DoVi 与 SDR）合并为一集，播放器内可切换
  版本，默认选择 SDR。

### 元数据
- 匹配 **Bangumi**（v0 API：搜索、海报、简介、评分、制作公司；条目吐槽箱、
  社区话题/日志）和 **AniList**（GraphQL：搜索、元数据、MAL 交叉 ID、评论、
  主要制作公司）。
- **查找元数据** 会为所有未关联的作品匹配最可能的结果；明显可疑的候选会放入
  **审核匹配** 等待快速人工确认。自动猜测的关联会显示置信度，可通过
  **更改匹配** 修正。
- 每个数据源的关联、元数据和社区索引都独立存储在 SQLite 中；数据源故障
  不会导致本地媒体库无法显示。社区条目可打开原始来源页面。
- 在磁盘上重命名文件夹后重新扫描，关联会跟随文件——身份迁移会保留元数据、
  个人记录和观看历史。

### 查找资源
- **查找资源**（侧边栏“发现”，或任意动画页面的工具栏）同时搜索十个动漫种子站——
  动漫花园、蜜柑计划、萌番组、Anime Garden、ACG.RIP、末日动漫、Nyaa（动画分类）、
  AnimeTosho、SubsPlease、TokyoTosho——并把不同站点上的同一个种子合并为一条
  （统一十六进制/Base32 info hash，合并来源、tracker 和 `.torrent` 链接）。
  只提供动漫站点；成人、游戏和漫画条目在解析时就会被剔除。
- 从动画页面打开时，会用这部作品的所有名称（Bangumi 中文名和原名、AniList
  罗马音、文件夹标题）一起搜索；能补上媒体库缺集的资源会标记为 **New**，
  勾选 **Missing Episodes** 只看这些。
- 每个标题都会解析出字幕组、集数或合集范围、分辨率、编码、片源以及字幕语言/
  形式（简/繁/日，内嵌/内封/外挂）。可按类型、分辨率、字幕和字幕组筛选；按
  最佳匹配、最新、做种数或体积排序；默认隐藏不相关的条目。
- 结果随各站点返回陆续显示；慢的或被拦截的站点不会拖住其他站点。
  **Source Details** 显示每个站点的状态和耗时，**Retry Failed** 只重试失败项。
- 每条资源可以：用种子客户端打开、复制磁力链接（支持多选）、保存 `.torrent`
  （按 info hash 校验）或打开原始页面。会记住最近的搜索。

### 下载
- **内置 BitTorrent 引擎**（静态链接 libtorrent）：下载资源无需另装客户端。
  退出后任务会保留进度，重启继续；可暂停、继续、移除（可选是否删除文件）、
  重新向 Tracker 汇报以扩大节点池。
- **下载**（侧边栏“来源”）显示进度、速度、做种/连接数、剩余时间和保存目录。
  目录会被记住；开始新下载时若目录不可用（硬盘拔出、目录被删），会自动改用
  最近可用的目录并给出提示，都不可用时回退到应用自己的目录。
- **连通性可见**，因为它决定 BT 速度上限：显示 DHT 节点数以及 UPnP/NAT-PMP
  是否成功映射端口；映射失败时会说明手动转发端口能带来什么。
- **边下边播**：顺序下载的任务在开头 32 MiB 落盘后即可播放，点播放按钮就用
  AnimeGod 自己的播放器打开，剩余部分继续下载；该文件的分片会被提到队列最前，
  让播放进度跑在下载前面。这类文件还没进媒体库，因此不会记录观看进度、不会
  自动缓存、也不匹配弹幕——这些等它进库后才有。
- **下载完成自动进库**：保存在媒体库目录内的任务完成后会自动重新扫描，作为普通
  剧集出现；保存在别处的任务则提供「把下载目录加入媒体库」。
- 引擎参数沿用 magnet-crawler 的调优：多个 DHT 引导节点、本地节点发现、PEX、
  向所有 Tracker 汇报、允许但不强制加密、同时监听 IPv4 与 IPv6，并为每个任务
  注入公共 Tracker。

### 订阅
- **追番自动下载**：一条规则由字幕组、分辨率、字幕语言、必含/排除关键词和起始
  集数组成。最快的创建方式是在「查找资源」里筛好之后点铃铛按钮。
- **订阅只追之后发布的**：新建订阅后才发布的资源才会下载，所以在季中订阅不会
  把已播的整季一次性拖回来；要回补旧集需要单独打开开关。
- **每集只下一个**，已在媒体库或之前下过的不再下；同一集里没人做种的会输给有
  节点的。没有集号的资源只有在规则指定了字幕组或关键词时才会自动下载，避免误下
  整季合集。
- 支持合作发布：规则写 `LoliHouse` 能匹配 `[喵萌奶茶屋&LoliHouse]`，这才是字幕组
  实际的发布方式。
- 启用的规则每 30 分钟检查一次，所有动作都记录在「Recent Activity」里——自动
  下载只有在看得见、关得掉的时候才让人放心。

### Bangumi 排行榜
- **Bangumi 排行榜** 可以浏览 Bangumi 发布的所有全站排名：全部五个频道
  （动画、书籍、音乐、游戏、三次元）以及网站提供的所有筛选项
  （分类/来源/题材/地区/受众/平台/分级…），每个频道一个菜单。
- 条目来自只读的 `next.bgm.tv/p1/subjects` JSON 接口（`sort=rank`）；
  筛选分类从各频道的浏览页面自动发现，新分类无需更新应用即可出现。
  bgm.tv 的筛选子路径受 Cloudflare 验证保护，排行榜本身从不请求这些路径。
- 排名行显示封面、全站排名（金/银/铜牌）、评分、评分人数和简介；
  **加载更多** 可翻阅多达数千个条目。已在本地媒体库中匹配的条目会带标记并
  直接链接到详情页，其余条目打开 bgm.tv 页面。

### 翻译
- 独立的翻译服务（`AnimeGodCore/Translation`），内置 **DeepL 兼容接口**：
  批量请求、自动识别免费/专业版端点、API 密钥保存在 macOS 钥匙串中、
  翻译结果缓存到本地数据库。
- 外语评论 **原文与译文并排显示**——原文从不被替换。

### 播放器
- 内嵌 libmpv（MPVKit）播放：H.264/HEVC/AV1、10-bit、VideoToolbox 硬件解码、
  多音轨/字幕轨、外挂字幕自动发现（`sub-auto=fuzzy` + `subs/字幕` 文件夹）、
  手动加载外部字幕。
- 章节、播放速度（0.5×–2×）、音量、字幕/音频延迟、时间轴、键盘快捷键
  （`Space`、`←/→`、`F`、`N/P`、`D`、`M`）、双击全屏、带分类标签的播放器内
  选集、不同编码版本菜单。
- HDR：基于信号的 HDR10/HLG/杜比视界检测，在支持的显示器上输出 16 位浮点
  BT.2020 EDR，自动 HDR 转 SDR 色调映射，以及诊断面板（**⌘⇧D**）。符合条件的
  杜比视界 Profile 8.4 MP4/MOV 文件使用 Apple 原生播放路径；MKV 和 Profile 7
  使用 HDR10 基础层。

### 剧集缓存
- **自动缓存**：外置硬盘上的剧集首次播放时，会在后台复制到本机（一次一个，
  分块复制并实时显示进度）；复制完成前播放继续从硬盘读取。
- **看完即释放**：剧集播放到 ≥90% 后关闭，会自动删除其自动缓存——这份副本只是
  首次播放到看完之间的缓冲，而不是永久副本。手动缓存从不自动删除。
- **手动缓存**：每集都有复制到本机的按钮（带实时进度和取消），动画页面还有
  **全部缓存**；对正在自动缓存的剧集发起手动缓存，会直接接管这份副本。
- **离线播放**：拔掉的硬盘仍保留完整索引——已缓存的剧集正常播放，其余显示
  请插入硬盘。播放时优先使用已完成的缓存，所以追番途中拔掉硬盘也不会打断
  当前这一集。
- **缓存管理器**（来源 → 剧集缓存）：总占用空间、按动画分组并显示观看标记、
  实时复制进度、取消、在访达中显示、单集删除、全部清除，以及两条自动规则的
  开关。副本存放在 `Application Support/AnimeGod/Episode Cache`，启动时和
  每次重新扫描后都会与数据库核对（清理孤立文件和崩溃残留的半成品）。

### 弹幕
- 叠加在视频上的原生渲染器（Core Animation 图层 + display link，文字位图
  缓存），从画面顶部开始排列，并与播放器自身的时钟同步。暂停时弹幕立即定格；
  拖动进度、改变速度和继续播放时，视频与弹幕保持同步。渲染器从不影响
  HDR/EDR 视频管线。
- 两个弹幕源，可在设置中选择——**弹弹play**、**Bilibili**，或两者合并：
  - 官方 **弹弹play 开放弹幕 API**：按文件哈希自动识别剧集，并提供基于元数据
    的选集面板，点击弹幕按钮即可打开。候选按标题、集数和媒体类型排序，无需把发布
    文件名复制到搜索框。特殊的发布版本仍可手动搜索标题。
  - **Bilibili**：无需账号。Bilibili 没有文件识别接口，因此按标题和集数匹配
    剧集，再从官方 protobuf 分段接口按该集自己的 `cid` 拉取弹幕——多 P 投稿
    也会取到对应分 P 的弹幕池。弹弹play 匹配不到的番，往往在这里能找到。
    可选的 `SESSDATA` Cookie（在设置中填写，保存在钥匙串）只是扩大你的账号
    可见范围；遇到区域限制或会员限定时会如实提示，不影响播放。
  - **合并**：同时获取两个弹幕池并合并，两边都有的弹幕只显示一条。
- 下载的弹幕按数据源和剧集缓存在本地数据库中，可离线重播并避免重复请求。
  需要获取最新弹幕时，使用 **刷新弹幕**。
- 播放栏控制：开关（`D`）、不透明度、字体大小、行距、显示区域和最大行数、
  滚动速度、同屏最大数量、按类型和彩色弹幕筛选、±10 秒时间偏移、刷新和重新
  匹配剧集——全部自动保存。同一行的弹幕之间保持间距，放不下的弹幕会被丢弃
  而不是重叠。需要在 [dev.dandanplay.com](https://dev.dandanplay.com) 免费申请
  AppId/AppSecret，并在 **设置** 中填写，凭据保存在钥匙串中。
- 针对弹幕密集番剧的筛选：10 秒内的重复弹幕合并为一条并显示 ×N 计数，
  密度滑杆可均匀减少其余弹幕（多次重复的弹幕始终保留），可隐藏过长的弹幕，
  屏蔽词支持普通文本或 `/正则表达式/`。
- **弹幕管理面板**（按 `M`，或从弹幕菜单打开）：视频旁的面板，列出最近 30 秒
  的弹幕，或搜索整集弹幕。点击弹幕跳转到对应时间；右键可屏蔽该文字或发送者。
  被隐藏的弹幕会显示是哪条规则隐藏了它，屏蔽词和屏蔽用户可以在面板或弹幕
  设置中管理。

### 在线字幕
- 视频没有你偏好语言（默认简体/繁体中文）的字幕时，AnimeGod 会识别番剧、季、
  集数和发布版本（字幕组/压制组、BD/WEB 来源、分辨率），并行搜索已配置的字幕
  站，并且只在足够有把握时自动加载最佳结果；否则用一个小提示让你挑选候选字幕。
- 字幕源（各自的密钥在设置中填写，保存在钥匙串里）：**射手网(伪) assrt.net**
  （中文字幕组存档，ASS）、**SubDL**（按 TMDB ID + 季/集搜索）、
  **OpenSubtitles**（按文件哈希精确匹配，仅 SRT）和 **Jimaku**（日文字幕，
  仅在偏好日文时使用）。任何一个源出错都不会影响其他源。
- 匹配优先看是否同一集、发布版本是否兼容——BD 字幕绝不会自动加载到 WEB 视频上，
  反之亦然——然后才按你的语言和格式顺序（ASS/SSA 优先于 SRT）。季度合集和 ZIP
  会解包出对应集；GBK/Big5 编码会转换为 UTF-8。
- 字幕菜单分为 **内嵌**、**外挂文件** 和 **在线** 三组；**在线字幕** 提供自动
  匹配、**搜索字幕…**（语言、格式、来源、字幕组、匹配度、版本、文件名）和已下载
  字幕。下载的字幕按集缓存，重播时无需再次搜索。ASS 由 libass 渲染，并使用字幕包
  自带的字体。
- 文件名表明中文字幕已内嵌（烧录）的版本（如 `[CHT]`、`[简日内嵌]`）默认不会
  搜索，可在设置中更改。

### 个人收藏
- 观看记录来自真实的播放会话（不足 15 秒的播放会被忽略）；播放到 90% 即标记
  该集为已看，并自动更新追番状态。
- 每部作品可设置状态、评分、笔记、评论、标签、收藏和重看次数——**排名与评分
  严格分开**，可在 **我的排名** 中调整顺序。
- **追番日记** 根据观看历史自动生成。
- **统计** 把一年变成一份报告：总观看时长、观看次数、看完的集数、按月/星期/
  小时的观看习惯、看得最多的动画和制作公司、你评分最高的作品——全部在本地
  计算。

## 开发

环境要求：macOS 14+、Xcode 26+、XcodeGen。

```sh
swift test
xcodegen generate
xcodebuild -project AnimeGod.xcodeproj -scheme AnimeGod -configuration Release build
```

- `AnimeGodCore`（SPM 包）包含模型、GRDB 数据库、扫描器/解析器、元数据
  数据源、翻译和统计——均可独立测试。
- 应用目标使用 SwiftUI + AppKit，播放基于 LGPL 版本的 MPVKit。分发二进制文件前
  请阅读 `THIRD_PARTY_NOTICES.md`。
- 可选的在线数据源测试：`ANIMEGOD_LIVE_TESTS=1 swift test --filter
  'Bangumi.*ProviderTests'`。
- 无界面播放器冒烟测试：使用 `-smokePlayerTest` 参数运行构建出的程序
  （自动播放第一集、切换全屏、输出布局尺寸）。

## 数据与隐私

所有数据——媒体库、元数据缓存、观看历史、个人记录、统计、翻译、弹幕匹配、
弹幕缓存以及剧集缓存索引——都保存在本地 SQLite 数据库中
（`~/Library/Containers/com.uhmmu.AnimeGod/Data/…`）；缓存的剧集文件位于同一
容器的 Application Support 文件夹中。不会上传任何数据。只有在你主动使用元数据
数据源、浏览 Bangumi 排行榜、使用你配置的翻译服务、开启弹幕时访问你选择的
弹幕源（弹弹play 和/或 Bilibili）、访问你配置的字幕站（会发送番剧标题、ID、
集数和文件名，OpenSubtitles 另有一个由文件 128 KiB 计算的哈希）、搜索资源站，以及下载时连接 BT 网络，才会
使用网络。BT 是点对点协议，和任何种子客户端一样，与你交换数据的节点能看到你的
IP 地址。
